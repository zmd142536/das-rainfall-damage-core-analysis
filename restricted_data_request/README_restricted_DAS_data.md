# Restricted raw DAS data

The complete raw DAS recordings are not included in this public release because of their large volume and site-sensitive experimental metadata.

Available public material:

- processed figure source data;
- plotting metadata for supplementary figures;
- DAS/CAT-RMS processing scripts;
- voxel damage-analysis scripts.

Raw DAS request procedure:

1. Contact the corresponding author at `[corresponding_author_email]`.
2. State requester name, affiliation, intended use, requested cases/time windows/channels, and preferred transfer method.
3. The authors will evaluate data-transfer feasibility and any applicable institutional data-sharing constraints.

Suggested manuscript wording:

> The complete raw DAS recordings are available from the corresponding author upon reasonable request at `[corresponding_author_email]`, subject to data-volume and institutional data-sharing constraints.
