#  Fig. 1的数字化数据


## Files

- `FigX_a_waveforms_digitized_approx.csv`:  (a) 的数据
- `FigX_b_psd_curves_digitized_approx.csv`:  (b)  0 to 500 Hz的PSD数据.
- `FigX_b1_low_frequency_psd_digitized_approx.csv`: (b1)  0 to 1 Hz的数据.

## Figure Interpretation Used

- Panel (a): red curve = microseismic signal; blue curve = background noise.
- Panel (b): red curve = event-included period; blue curve = rainfall-only period.
- Panel (b1): low-frequency inset corresponding to the red and blue PSD curves.
- Target band shown in panel (b): approximately 50-180 Hz.
- Rainfall-only/background window: first 30 min after rainfall onset.
- Event-included window: a 30-min window starting approximately 5 h after rainfall onset.
